### Local implementation evidence: 2026-08-15

- `make test` passed on the implementation tree with Rust 1.85.0: 58 ESM
  files, 8 LauncherService cases, 81 Python tests, 10 Rust unit tests plus
  doctests, rustfmt, Clippy with warnings denied, release-contract checks, and
  doctor behavior.
- `make test-install` passed with an isolated staging root and no suite-owned
  file or symlink left after uninstall. System installs omit extension-local
  schema directories; development installs keep valid compiled local schemas.
- A clean `debian:trixie-slim` container built the amd64 package with Debian's
  Rust 1.85.0. Package metadata reports version `0.1.0~beta1-1`; inspection
  found no wallpapers, background metadata, or `gschemas.compiled`.
- A second clean Debian 13 container completed forced-dependency install,
  doctor, purge, and owned-path removal. The full dependency-resolved install
  remains a CI release gate, so its checklist item stays open.
- `cargo-deny 0.20.2 --workspace --all-features --locked` passed advisories,
  licenses, and sources. Git dependency licenses are pinned to verified files:
  `cosmic-client-toolkit` is GPL-3.0-or-later and `switcheroo-control` is
  MPL-2.0.
